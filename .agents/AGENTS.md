Proyecto Hydration Calculator. Tecnologías: React Native con Expo SDK 54 TypeScript NativeWind para frontend y FastAPI con Python para backend. Estructura: frontend/ contiene app React Native, backend/ contiene API FastAPI. Reglas: TypeScript en frontend, Pydantic en backend, patrón repositorio, endpoints versionados /api/v1/, NativeWind para estilos. Convenciones: componentes PascalCase, hooks camelCase con use, servicios camelCase, modelos PascalCase. Fórmulas: gramos = volumen * (graduacion/100) * 0.789, factor = 0.73 hombre o 0.66 mujer, BAC = gramos / (peso * factor), agua = BAC * 5000. Para tareas específicas usar archivos en .agents/tasks/. Para roles usar .agents/roles/.
